## Использование

### Подключение стилей
Все CSS файлы уже подключены в `base.html`:
```html
<link href="{% static 'css/style.css' %}" rel="stylesheet">
<link href="{% static 'css/components.css' %}" rel="stylesheet">
<link href="{% static 'css/corporate.css' %}" rel="stylesheet">
```

### Примеры использования корпоративных компонентов
```html
<!-- Корпоративная кнопка -->
<button class="btn-corporate">Действие</button>

<!-- Корпоративная карточка -->
<div class="corporate-card">
    <h3>Заголовок</h3>
    <p>Содержимое</p>
</div>

<!-- Корпоративный бейдж -->
<span class="corporate-badge">Статус</span>
```
