# Система рекомендаций на основе Gemma LLM

## Описание

Система рекомендаций использует Google Gemma LLM для анализа соответствия резюме и вакансий. Система интегрирована с существующей HR платформой и предоставляет персонализированные рекомендации для кандидатов.

## Возможности

- 🤖 **LLM-анализ**: Использует Google Gemma для глубокого анализа соответствия
- 📊 **Гибридный подход**: Комбинирует LLM и традиционные алгоритмы
- ⚡ **Кэширование**: Результаты кэшируются для повышения производительности
- 🔍 **Расширенный поиск**: Фильтры по опыту, зарплате, удаленной работе
- 📱 **API**: REST API для интеграции с мобильными приложениями

## Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка базы данных

#### Вариант A: Использование готовой БД PostgreSQL

1. Установите PostgreSQL
2. Создайте базу данных:
```sql
CREATE DATABASE hr_platform;
```

3. Настройте подключение в `env.local`:
```env
DB_NAME=hr_platform
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432
```

4. Импортируйте готовые данные:
```bash
python import_data.py
```

#### Вариант B: Использование SQLite (для разработки)

Измените настройки в `settings.py`:
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

### 3. Настройка Hugging Face API

1. Получите токен на [Hugging Face](https://huggingface.co/settings/tokens)
2. Добавьте токен в `env.local`:
```env
HUGGINGFACE_API_TOKEN=your-token-here
```

### 4. Применение миграций

```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

## Использование

### Для кандидатов

1. Войдите в систему как кандидат
2. Перейдите в "Рекомендации" на дашборде
3. Просматривайте персонализированные рекомендации вакансий
4. Используйте расширенный поиск для фильтрации

### Для HR

1. Войдите в систему как HR
2. Откройте вакансию
3. Просматривайте рекомендации резюме
4. Обновляйте рекомендации при необходимости

## API Endpoints

### Получение рекомендаций для кандидата
```
GET /recommendations/api/
```

### Поиск рекомендаций с фильтрами
```
GET /recommendations/search/?q=python&experience=junior&salary_min=50000
```

### Обновление рекомендаций для HR
```
POST /recommendations/hr/{vacancy_id}/refresh/
```

## Архитектура системы

### Компоненты

1. **GemmaRecommendationService**: Основной сервис для работы с LLM
2. **RecommendationService**: Гибридный сервис рекомендаций
3. **Views**: Контроллеры для веб-интерфейса
4. **Templates**: HTML шаблоны для отображения

### Алгоритм работы

1. **Сбор данных**: Извлечение информации из резюме и вакансии
2. **LLM-анализ**: Отправка данных в Gemma API
3. **Традиционный анализ**: Применение правил и фильтров
4. **Комбинирование**: Объединение результатов с весами
5. **Кэширование**: Сохранение результатов для повторного использования

### Настройки

```python
# config.py
GEMMA_CONFIG = {
    'MODEL_NAME': 'google/gemma-2-2b-it',
    'API_URL': 'https://api-inference.huggingface.co/models/google/gemma-2-2b-it',
    'MAX_TOKENS': 512,
    'TEMPERATURE': 0.7,
    'TIMEOUT': 30,
}

RECOMMENDATION_CONFIG = {
    'MIN_SCORE_THRESHOLD': 0.3,
    'MAX_RECOMMENDATIONS': 10,
    'CACHE_DURATION_HOURS': 24,
    'ENABLE_LLM_ANALYSIS': True,
}
```

## Мониторинг и отладка

### Логирование

Система ведет подробные логи:
- Ошибки API
- Время выполнения запросов
- Статистика использования

### Кэширование

Результаты кэшируются на 24 часа для повышения производительности.

### Fallback режим

При недоступности LLM API система автоматически переключается на традиционные алгоритмы.

## Производительность

- **Время ответа**: < 2 секунды для большинства запросов
- **Кэширование**: 24 часа для рекомендаций
- **Масштабируемость**: Поддержка до 1000 одновременных пользователей

## Безопасность

- Токены API хранятся в переменных окружения
- Валидация входных данных
- Защита от SQL-инъекций
- Ограничение частоты запросов к API

## Разработка

### Добавление новых правил рекомендаций

1. Создайте правило в админке Django
2. Добавьте логику в `RecommendationService`
3. Протестируйте на тестовых данных

### Кастомизация LLM промптов

Измените метод `_create_analysis_prompt` в `GemmaRecommendationService`.

### Добавление новых фильтров

Расширьте метод `search_recommendations` в views.
