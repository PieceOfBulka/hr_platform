# HR Platform - Система рекомендаций вакансий

Интеллектуальная система рекомендаций для HR платформы, которая подбирает подходящие вакансии для соискателей на основе их навыков, опыта и предпочтений.

## Возможности

- **Умные рекомендации**: Алгоритм анализирует навыки, опыт и специальность соискателя
- **Многофакторная оценка**: Учитывает соответствие навыков, опыт работы, текстовое сходство и актуальность
- **Веб-интерфейс**: Удобный интерфейс для просмотра рекомендаций
- **REST API**: Полноценное API для интеграции с другими системами
- **Гибкая настройка**: Легко настраиваемые весовые коэффициенты для разных факторов

## Архитектура

### База данных
- **users** - Пользователи системы (HR, соискатели, представители вузов, админы)
- **companies** - Компании-работодатели
- **vacancies** - Вакансии
- **resumes** - Резюме соискателей
- **list_of_skills** - Справочник навыков
- **vacancy_skills** - Связь вакансий и навыков
- **applications** - Отклики на вакансии
- **recommendations** - Сохраненные рекомендации

### Алгоритм рекомендаций
Система использует многофакторный анализ:

1. **Соответствие навыков (40%)** - Сравнение навыков резюме и вакансии
2. **Опыт работы (20%)** - Анализ требований к опыту
3. **Текстовое сходство (20%)** - TF-IDF анализ описаний
4. **Соответствие специальности (10%)** - Сопоставление специальности и должности
5. **Актуальность (10%)** - Свежесть вакансии

## Установка и запуск

### Требования
- Python 3.8+
- PostgreSQL (или SQLite для разработки)

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Настройка базы данных
```bash
# Для PostgreSQL
export DATABASE_URL="postgresql://user:password@localhost/hr_platform"

# Для SQLite (разработка)
export DATABASE_URL="sqlite:///./hr_platform.db"
```

### Создание тестовых данных
```bash
python seed_data.py
```

### Запуск приложения
```bash
python main.py
```

Приложение будет доступно по адресу: http://localhost:8000

## API Endpoints

### Рекомендации
- `GET /api/recommendations/resume/{resume_id}` - Рекомендации для резюме
- `GET /api/recommendations/user/{user_id}` - Рекомендации для пользователя
- `GET /api/recommendations/stats/{resume_id}` - Статистика рекомендаций

### Данные
- `GET /api/vacancies` - Список вакансий
- `GET /api/skills` - Список навыков
- `POST /api/resumes` - Создание резюме

## Использование

### Веб-интерфейс
1. Откройте http://localhost:8000
2. Введите ID резюме (1-5 для тестовых данных)
3. Получите персонализированные рекомендации

### API
```python
import requests

# Получить рекомендации для резюме
response = requests.get("http://localhost:8000/api/recommendations/resume/1")
recommendations = response.json()

for rec in recommendations:
    print(f"Вакансия: {rec['vacancy_title']}")
    print(f"Компания: {rec['company_name']}")
    print(f"Совместимость: {rec['score']:.1%}")
    print(f"Причина: {rec['reason']}")
```

## Настройка алгоритма

В файле `recommendation_engine.py` можно настроить весовые коэффициенты:

```python
# Итоговая оценка (взвешенная сумма)
final_score = (
    skill_score * 0.4 +      # Навыки
    experience_score * 0.2 + # Опыт
    text_score * 0.2 +       # Текстовое сходство
    specialty_score * 0.1 +  # Специальность
    freshness_score * 0.1    # Актуальность
)
```
