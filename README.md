# HR Платформа ОЭЗ "Технополис Москва"

Централизованная система управления карьерными сервисами для технологического кластера.

## Описание

HR-платформа предназначена для:
- Централизованного управления вакансиями и кандидатами от всех резидентов ОЭЗ
- Автоматизации взаимодействия с образовательными учреждениями по вопросам стажировок
- Обеспечения быстрого и качественного закрытия вакансий
- Сбора аналитики по рынку труда в технологической сфере Москвы

## Роли пользователей

1. **Администратор ОЭЗ** - управление платформой, модерация контента, аналитика
2. **HR компании** - создание вакансий, поиск кандидатов, управление откликами
3. **Представитель вуза** - создание стажировок, поиск партнеров
4. **Соискатель** - поиск работы, создание резюме, отклики на вакансии

## Установка и запуск

### Требования
- Python 3.8+
- Django 4.2+

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd hr_platform
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл .env на основе env.example:
```bash
cp env.example .env
```

5. Выполните миграции:
```bash
python manage.py makemigrations
python manage.py migrate
```

6. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

7. Запустите сервер разработки:
```bash
python manage.py runserver
```

## Основной функционал

### Для HR компаний:
- Создание и управление вакансиями
- Просмотр базы резюме
- Управление откликами
- Аналитика по вакансиям

### Для представителей вузов:
- Создание заявок на стажировки
- Поиск партнеров среди компаний
- Управление заявками на стажировки

### Для соискателей:
- Поиск вакансий и стажировок
- Создание и управление резюме
- Отклики на вакансии
- Отслеживание статуса откликов

### Для администраторов:
- Модерация вакансий и стажировок
- Управление пользователями
- Аналитика платформы
- Настройка системы

## Технологии

- **Backend**: Django 4.2, Python 3.8+
- **Frontend**: Bootstrap 5, HTML5, CSS3, JavaScript
- **База данных**: SQLite (разработка), PostgreSQL (продакшн)
- **Дополнительно**: Pillow (работа с изображениями), django-crispy-forms
