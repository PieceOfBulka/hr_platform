### 🎯 О проекте

**HR-платформа "ТЕХНОПОЛИС МОСКВА"** - это современная веб-платформа для централизованного управления HR-процессами в технологическом кластере ОЭЗ "Технополис Москва". Платформа объединяет компании-резиденты, учебные заведения, соискателей и администрацию ОЭЗ в единую экосистему.

### ✨ Ключевые возможности

- 🏢 **Личные кабинеты** для всех участников кластера
- 📝 **Управление вакансиями** с модерацией и автоснятием
- 🎓 **Стажировки** для связи вузов и компаний
- 👤 **Резюме и портфолио** с общим банком
- 🧠 **Умные рекомендации** по подбору кандидатов
- 🧪 **Тесты навыков** для проверки компетенций
- 📊 **Аналитика и отчеты** для администрации
- 🔍 **Публичный каталог** с поиском и фильтрацией

### 🚀 Быстрый старт

#### 1. Установка
```bash
# Клонирование репозитория
git clone <repository-url>
cd hr_platform

# Создание виртуального окружения
python -m venv venv

# Активация окружения
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

#### 2. Настройка базы данных
```bash
# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Загрузка тестовых данных
python manage.py loaddata fixtures/test_data.json
python manage.py loaddata fixtures/extended_test_data.json
```

#### 3. Запуск
```bash
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ в браузере

### 🛠️ Технологический стек

- **Backend**: Django 4.2 + Python 3.8
- **Frontend**: HTML5 + CSS3 + JavaScript + Bootstrap 5
- **База данных**: SQLite (разработка) / PostgreSQL (продакшн)
- **Стилизация**: Custom CSS + Font Awesome + Google Fonts
- **Безопасность**: CSRF, аутентификация, авторизация по ролям

### 🎬 Демо-сценарии

#### Сценарий 1: HR создает вакансию
1. HR авторизуется → "Мои вакансии"
2. Заполняет детальную форму
3. Отправляет на модерацию
4. Админ одобряет → вакансия публикуется

#### Сценарий 2: Соискатель откликается
1. Находит вакансию → "Откликнуться"
2. Заполняет сопроводительное письмо
3. Ставит галочку "Разместить в общем банке"
4. Отклик поступает HR + резюме становится публичным

#### Сценарий 3: Система рекомендаций
1. HR получает отклик
2. Система анализирует резюме
3. Генерирует рекомендации:
   - "Провести собеседование" (высокий приоритет)
   - "Назначить тест навыков" (средний приоритет)
