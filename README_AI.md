# 🤖 AI-Powered HR Platform - Система рекомендаций

## 🎯 Описание

Это улучшенная версия HR платформы с интеграцией AI для рекомендации вакансий на основе анализа резюме. Система использует Hugging Face API для семантического анализа текстов и предоставляет точные рекомендации с объяснениями.

## ✨ Основные возможности

- **AI-анализ резюме и вакансий** с использованием Hugging Face API
- **Семантическое сопоставление** текстов с помощью эмбеддингов
- **Многофакторная оценка совместимости**:
  - Совпадение навыков (40%)
  - Семантический анализ текста (30%)
  - Совпадение специализации (20%)
  - Свежесть вакансии (10%)
- **Детальные объяснения** рекомендаций
- **Fallback режим** без токена Hugging Face
- **Современный веб-интерфейс** с поддержкой AI

## 🔧 Конфигурация

### Hugging Face API Token (опционально)

Для полной функциональности AI системы:

1. Зайдите на [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
2. Создайте новый токен
3. Добавьте его в `.env` файл:
   ```
   HUGGINGFACE_TOKEN=your_token_here
   ```

**Примечание**: Система работает и без токена, используя fallback алгоритмы.

## 📊 API Endpoints

### Обычные рекомендации
- `GET /api/recommendations/resume/{resume_id}` - Рекомендации для резюме
- `GET /api/recommendations/user/{user_id}` - Рекомендации для пользователя

### AI рекомендации
- `GET /api/ai/recommendations/resume/{resume_id}` - AI рекомендации для резюме
- `GET /api/ai/recommendations/user/{user_id}` - AI рекомендации для пользователя

### Другие endpoints
- `GET /api/vacancies` - Список вакансий
- `GET /api/skills` - Список навыков
- `POST /api/resumes` - Создание резюме

## 🔍 Примеры использования

### Получение AI рекомендаций через API

```python
import requests

# AI рекомендации для резюме ID 1
response = requests.get("http://localhost:8000/api/ai/recommendations/resume/1")
recommendations = response.json()

for rec in recommendations:
    print(f"Вакансия: {rec['vacancy_title']}")
    print(f"Компания: {rec['company_name']}")
    print(f"Совместимость: {rec['score']:.2%}")
    print(f"Причина: {rec['reason']}")
    print("---")
```

### Создание резюме через API

```python
import requests

resume_data = {
    "full_name": "Иван Петров",
    "email": "ivan@example.com",
    "summary": "Опытный Python разработчик",
    "specialty": "Backend разработчик",
    "skill_ids": [1, 2, 3]  # ID навыков
}

response = requests.post("http://localhost:8000/api/resumes", json=resume_data)
result = response.json()
print(f"Создано резюме с ID: {result['resume_id']}")
```

## 🐛 Устранение неполадок

### Проблемы с Hugging Face API
- Проверьте токен в `.env` файле
- Убедитесь в стабильности интернет-соединения
- Система автоматически переключится на fallback режим

### Проблемы с базой данных
- Убедитесь, что SQLite файл доступен для записи
- Запустите `python setup_ai_system.py` для пересоздания данных

### Проблемы с зависимостями
```bash
pip install --upgrade -r requirements.txt
```

## 📈 Производительность

- **Без токена**: ~100ms на рекомендацию
- **С токеном**: ~2-5s на рекомендацию (зависит от API)
- **Кэширование**: Рекомендации сохраняются в БД
- **Fallback**: Автоматическое переключение при ошибках API
