## 🎯 Обзор проекта

### Название
**HR-платформа "ТЕХНОПОЛИС МОСКВА"**

### Назначение
Централизованная веб-платформа для управления HR-процессами в технологическом кластере ОЭЗ "Технополис Москва"

### Целевая аудитория
- **Компании-резиденты** ОЭЗ
- **Учебные заведения** (вузы, колледжи)
- **Соискатели** IT-специалистов
- **Администрация** ОЭЗ

---

## ⚠️ Проблематика

### Текущие проблемы
1. **Разрозненность данных**
   - Отсутствие единой базы вакансий и резюме
   - Изолированные HR-системы каждой компании
   - Невозможность получения сводной аналитики

2. **Неэффективность процессов**
   - Ручная обработка заявок
   - Дублирование работы HR-менеджеров
   - Долгий процесс подбора кандидатов

3. **Отсутствие специализации**
   - Общие платформы не адаптированы для IT
   - Нет инструментов для стажировок
   - Отсутствие проверки навыков

4. **Плохой пользовательский опыт**
   - Работа с таблицами и почтой
   - Отсутствие рекомендаций
   - Низкая скорость обработки

## 🏗️ Архитектура системы

### Технологический стек
- **Backend**: Django 4.2 + Python 3.8
- **Frontend**: HTML5 + CSS3 + JavaScript + Bootstrap 5
- **База данных**: SQLite (разработка) / PostgreSQL (продакшн)
- **Стилизация**: Custom CSS + Font Awesome + Google Fonts

### Структура приложений
```
hr_platform/
├── accounts/          # Управление пользователями
├── vacancies/         # Вакансии и отклики
├── internships/       # Стажировки
├── resumes/           # Резюме и портфолио
├── moderation/        # Модерация контента
├── catalog/           # Публичный каталог
├── skills/            # Тесты навыков
└── recommendations/   # Рекомендательная система
```

### Модель данных
- **Пользователи**: 4 роли (Admin, HR, University, Candidate)
- **Вакансии**: с модерацией и автоснятием
- **Стажировки**: связь вузов и компаний
- **Резюме**: с опытом работы и образованием
- **Тесты**: проверка навыков кандидатов
- **Рекомендации**: умная фильтрация и советы

## 🎬 Демонстрация

### Главная страница
- **Hero-секция** с логотипом "ТЕХНОПОЛИС МОСКВА"
- **Статистика** кластера в реальном времени
- **Поиск** вакансий и стажировок
- **Каталог** с фильтрацией

### Процесс создания вакансии
1. HR авторизуется в системе
2. Переходит в "Мои вакансии"
3. Заполняет детальную форму
4. Вакансия отправляется на модерацию
5. После одобрения публикуется в каталоге

### Процесс отклика соискателя
1. Соискатель находит подходящую вакансию
2. Нажимает "Откликнуться"
3. Заполняет сопроводительное письмо
4. Выбирает "Разместить в общем банке"
5. Отклик поступает HR + резюме становится публичным

### Система рекомендаций
1. HR получает отклик
2. Система анализирует резюме
3. Генерирует рекомендации:
   - "Провести собеседование" (высокий приоритет)
   - "Назначить тест навыков" (средний приоритет)
   - "Телефонное интервью" (низкий приоритет)
