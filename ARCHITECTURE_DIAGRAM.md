## Потоки данных

### 1. Создание вакансии
```
HR → Vacancies App → Moderation → Admin → Published → Catalog
```

### 2. Отклик соискателя
```
Candidate → Application → HR Dashboard → Recommendations → Action
```

### 3. Система рекомендаций
```
Resume + Vacancy → RecommendationService → Score → HR Tips
```

### 4. Тесты навыков
```
Candidate → SkillTest → Questions → Answers → Score → Certificate
```

## Интеграции

### Внутренние
- **Accounts** ↔ **Vacancies** (пользователи и вакансии)
- **Resumes** ↔ **Recommendations** (резюме и рекомендации)
- **Skills** ↔ **Resumes** (тесты и навыки)
- **Moderation** ↔ **All Apps** (модерация всего контента)

### Внешние (планируемые)
- **Email** уведомления
- **SMS** для важных событий
- **Social Media** интеграция
- **External HR** системы

## Масштабирование

### Горизонтальное
- **Load Balancer** для распределения нагрузки
- **Multiple Django** instances
- **Database** репликация
- **CDN** для статических файлов

### Вертикальное
- **More CPU/RAM** для сервера
- **Faster Database** (PostgreSQL)
- **Caching** (Redis)
- **Queue** система (Celery)
